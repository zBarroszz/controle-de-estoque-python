# Controle de Estoque em Python

Projeto pessoal desenvolvido para praticar Python e banco de dados SQLite.

## Funcionalidades atuais

- Cadastro de produtos
- Registro de categoria e unidade de medida
- Definição de quantidade atual e quantidade mínima
- Validação de campos e valores numéricos
- Armazenamento dos produtos em banco de dados SQLite
- Consulta dos itens cadastrados

## Tecnologias

- Python
- SQLite
- Biblioteca `sqlite3`

## Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

   `python main.py`

O banco de dados `estoque.db` é criado localmente na primeira execução.
